========================================
 Pons / StonkFun 监控看板 —— 部署包
========================================

【先做这个】
  双击打开【部署指南.md】，里面每一步都写了，照着做就行。

【文件是干什么的】
  index.html          → 看板本体（唯一必须的文件，别删别改名）
  部署指南.md          → 完整部署教程，零基础也能看懂
  deploy.sh           → 服务器上跑这个，自动装好一切
  push.sh             → 以后更新看板，本地跑这个推上去
  nginx.conf          → 服务器配置参考（deploy.sh 会自动处理）
  Dockerfile          → Docker 部署用（可选）
  docker-compose.yml  → Docker 部署用（可选）

【有服务器的人，三步走】
  1) 本地终端执行：scp -r deploy root@你的服务器IP:/root/
  2) 登录服务器：  ssh root@你的服务器IP
  3) 一键部署：    cd /root/deploy && bash deploy.sh

  最后屏幕会打印出网址，形如 http://你的IP:8080

【打不开怎么办】
  90% 是云服务商【安全组】没放行 8080 端口。
  登录阿里云/腾讯云控制台 → 找到这台服务器 → 安全组 → 放行 TCP 8080。

【以后更新】
  在 Mac 上执行：bash deploy/push.sh 你的服务器IP

【提示】
  解压后如果中文文件名显示乱码，请用 7-Zip 或 Keka 解压。
