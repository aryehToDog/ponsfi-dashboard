## 剩下要你做的（共 3 步）

### 第 1 步 · 买域名（5 分钟）

1. 打开 腾讯云 → https://dnspod.cloud.tencent.com/
2. 搜索框输入 `ponspulse`，勾选 **.com**
3. 加入购物车 → 结算 → 付款（首年约 30~80 元）
4. 买完会提示做 **域名实名认证**，按提示上传身份证（1 天内通过）

**买完把域名复制给我，我帮你配 DNS 解析。**

### 第 2 步 · 开 8080 端口（2 分钟）⭐ 关键

腾讯云默认只开了 80 端口，8080 必须手动开，否则域名还是打不开。

1. 腾讯云控制台 → **轻量应用服务器** → 点进你的实例（<你的服务器IP>）
2. 上方切到 **防火墙** 标签
3. 点 **添加规则**
4. 填：
   - 应用类型：**自定义**
   - 协议：**TCP**
   - 端口：**8080**
   - 来源：**全部 IPv4**（0.0.0.0/0）
   - 备注：看板备用端口
5. 点 **确定**

### 第 3 步 ·（可选，但强烈建议）提交备案

备案通过后，网址就能从 `http://ponspulse.com:8080` 变成干净的 `http://ponspulse.com`

- 位置：腾讯云控制台 → 搜索「备案」→ 进入备案小程序
- 需要：身份证 + 人脸识别 + 你的服务器（有效期已满足要求）
- 时间：1~3 周
- 费用：**免费**
- 注意：域名注册后要等 3~5 天（实名认证同步）才能提交备案

## 常见问题

**Q：为什么域名不加 :8080 打不开？**
A：国内服务器上，没备案的域名会被腾讯云在 80/443 端口拦截（跳到 webblock 页面）。8080 这类非标准端口不拦。

**Q：备案期间网站要关吗？**
A：不用。用 `:8080` 那个网址一直能用。

**Q：换域名麻烦吗？**
A：不麻烦，告诉我新域名，我在服务器上改一行配置就行。

**Q：服务器密码忘了？**
A：腾讯云控制台 → 实例 → 重置密码（用户名选 `ubuntu`）。
